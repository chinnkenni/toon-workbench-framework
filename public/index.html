把下一台服务器接入机柜

控制台运行在这台 Windows，通过 SSH 连接你的 Ubuntu / Linux 服务器。监控无需在远端额外安装 Agent。

  1. 确认服务器能从本机连接

    启用 SSH，并让服务器与本机处于同一网络，或通过你已有的 VPN 连通。

  2. 授权 SSH 公钥

    将 Windows 上的公钥加入服务器用户的 ~/.ssh/authorized_keys。私钥保留在本机，不要上传到服务器或聊天。

    ssh 用户名@服务器IP

    首次连接时核对服务器的主机指纹并确认；控制台不会自动信任陌生主机。

  3. 点击「接入服务器」

    填写名称、地址、用户名和本机私钥路径。新增后自动检查连接，并开始采集真实指标。远端需要 Python 3 和 systemd；NVIDIA 指标需要 nvidia-smi。

  4. 完成开机配置

    点击服务器下方「准备开机配置」，在远端终端用 sudo 执行生成的脚本。它会启用开机 SSH、关闭自动休眠并允许用户服务常驻。

控制台在 Windows 登录后自动启动。服务器开机并联网后会重新被发现。断电恢复启动需要 BIOS 支持；固定 IP 建议在路由器中保留 DHCP 地址。这里的「接管」指通过已授权 SSH 执行维护任务，当前不包含无人值守自动修复。
